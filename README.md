# Saxons FRC Utility Classes
- Full I/O layer to simplify controlling/logging/simulating mechanisms
- Command factories that port legacy simple command types to the new Commands v3 API
- Subsystem abstract class with enable(), disable(), and periodic() methods
- Xbox controller rumble manager with priority system
- PhoenixUtil.java and SparkUtil.java (used in I/O layer)
